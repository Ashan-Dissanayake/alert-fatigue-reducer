# Alert Fatigue Reducer

A rule-based production alert correlation system that groups
related monitoring alerts into incidents to reduce alert fatigue.

## Problem

Production monitoring systems can generate multiple alerts
for the same underlying operational event.

This can increase alert volume and make incident investigation
more difficult.

## Goal

Identify and group related alerts into a single incident using
an explainable rule-based correlation engine.

## Tech Stack

- Java
- Spring Boot
- PostgreSQL
- Flyway
- Angular
- Docker
- JUnit 5

## Architecture

Modular monolith with feature-oriented modules.
